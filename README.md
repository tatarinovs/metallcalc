Кроссплатформенный инженерный калькулятор для точного расчёта веса и объёма металлического проката. Приложение написано на **Flutter** и компилируется в нативные приложения под Windows, Android, и другие платформы.

## ✨ Ключевые особенности

- **Адаптивный UI**: Умный интерфейс, который автоматически перестраивается под смартфоны, планшеты и десктопные окна (Landscape/Portrait).
- **Широкая база материалов**: Встроенная локальная база данных, включающая черные металлы, цветные металлы, спецсплавы и огромный список марок припоя.
- **Поддержка различных профилей**: Лист, Круг, Труба, Шестигранник и другие виды геометрических сечений проката.
- **Высокая инженерная точность**: Расчёт массы в килограммах, тоннах, граммах и миллиграммах с правильным округлением до нужных долей.
- **Интеграция с ОС (Windows)**: Нативный C++ код в `windows/runner` автоматически запоминает и восстанавливает размер и позицию окна при запусках через реестр Windows.
- **Portable версия**: Программа пакуется в 1 единственный `.exe` файл (при помощи Enigma Virtual Box), который можно переносить на флешке и запускать без установки.

## 🛠 Технологический стек

- **Dart 3 / Flutter** — пользовательский интерфейс и бизнес-логика.
- **C++ (Win32 API)** — системная обвязка и интеграция с ОС под Windows.
- **Zero-Dependency** — сведено к минимуму использование сторонних плагинов для обеспечения максимальной скорости работы и минимального размера бинарника.

## 🚀 Сборка

В корневой директории присутствует скрипт `build_all.bat`. Он выполняет полную сборку релизной версии приложения
> *(Опционально) Использует консольную утилиту Enigma Virtual Box (`enigmavbconsole.exe`) для упаковки всех файлов в один портативный `.exe` бинарник.
