Кроссплатформенный калькулятор теоретической массы и объёма металлического проката. Приложение написано на **Flutter** и собирается для Windows, Android и Web.

## ✨ Ключевые особенности

- **Адаптивный UI**: Умный интерфейс, который автоматически перестраивается под смартфоны, планшеты и десктопные окна (Landscape/Portrait).
- **Широкая база материалов**: Встроенная локальная база данных, включающая черные металлы, цветные металлы, спецсплавы и припои.
- **Поддержка различных профилей**: Лист, Круг, Шестигранник, Труба, Фасонный прокат и другие виды геометрических сечений проката.
- **Удобное представление результата**: Масса автоматически отображается в миллиграммах, граммах, килограммах или тоннах.
- **Интеграция с ОС (Windows)**: Нативный C++ код автоматически запоминает и восстанавливает размер и позицию окна.
- **Portable версия**: При наличии Enigma Virtual Box программа дополнительно пакуется в один `.exe`. Без Enigma создаётся обычный переносимый Windows-каталог.
- **Режим очистки**: Программу можно запустить с флагом `-u` (например, `MetallCalc.exe -u`), чтобы полностью удалить все сохраненные настройки и следы использования в системе.

## 🛠 Технологический стек

- **Dart 3 / Flutter** — пользовательский интерфейс и бизнес-логика.
- **C++ (Win32 API)** — системная обвязка и интеграция с ОС под Windows.
- **Zero-Dependency** — сведено к минимуму использование сторонних плагинов для обеспечения максимальной скорости работы и минимального размера бинарника.

## 💻 Системные требования

- **Windows:** Windows 10 (64-bit) или новее.
- **Android:** Android 7.0 (API 24) или новее.

## 🚀 Сборка

По умолчанию Android release-сборка подписывается стандартным debug-ключом и подходит для локальной установки и тестирования. Для публикации и последующих обновлений создайте постоянный ключ издателя:

```powershell
keytool -genkeypair -v -keystore android/metallcalc-release.jks -alias metallcalc -keyalg RSA -keysize 4096 -validity 10000
Copy-Item android/key.properties.example android/key.properties
```

Заполните реальные пароли в `android/key.properties`. При наличии этого файла сборка автоматически использует издательский ключ вместо debug-ключа. Файл свойств и ключ исключены из Git; сохраните резервную копию ключа, иначе обновлять опубликованное приложение будет невозможно.

Скрипт `build_all.bat` останавливается при первой ошибке и создаёт:

- APK для ARM32, ARM64 и x86_64, подписанные настроенным издательским или стандартным debug-ключом;
- переносимый Windows-каталог `releases/windows`;
- `releases/MetallCalc.exe`, если установлен Enigma Virtual Box;
- Web-сборку в `releases/web` для публикации по пути `/calc/`.

## Ограничения расчёта

Формулы используют идеализированные геометрические сечения. Радиусы гиба, скругления, уклоны полок, производственные допуски и разброс плотности материала не учитываются. Для приёмочных и закупочных расчётов сверяйте результат с сортаментом и нормативной массой по применимому ГОСТ.
